Ella Backups

Personal monitoring-history backups to Google Drive.

Ella Backups is a personal-use backup configuration associated with the Ella Monitoring / PicoData project. It is designed to copy monitoring-history backup archives from an owner-operated device to the owner's private Google Drive, and retrieve them when a restore is needed.

Why Google Drive access is requested

The configuration uses rclone to create a dedicated backup folder, upload archives, list and download those archives, and remove older backup versions according to the owner's chosen retention settings.

It requests the Google Drive drive.file permission, which limits access to files and folders created by this configuration. The monitoring database is not published on this website or in the public source repository.

Personal use

This is not a public backup service. Google account authorisation and backup operation are controlled by the owner on their own device. This website has no sign-in form, tracking scripts or advertising.
