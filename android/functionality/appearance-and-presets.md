# Appearance and viewer presets

Updated in **0.26 / build 8**.

Themes contain colour roles only, with name/format metadata. Named files remain in Downloads/ella-monitoring/themes; older themes are read compatibly. Font belongs to viewer settings/presets and is selected at the bottom left of Edit theme, with Back at the right and its choices opening above. Choosing/editing a theme preserves the font and affects only the Theme modification indication. Preset save/load/update does not include or restore colours/theme selection.

Title text, Title background and Title outline independently style Currents:, Ella Monitoring and Temps:. Missing title text in an older theme inherits general Text. Central/environmental Gauge panel 1/2, their outlines and Highlight 1/2 colours retain the central/environmental grouping. All colour roles save/load and compare independently. The colour-editor list groups related options; fixed green/red flag semantics remain distinct.

The shared picker accepts exactly six RGB hex digits, with optional # and whitespace trimming. Incomplete or invalid typing does not change the colour; invalid OK gives feedback and keeps the picker open. Wheel changes update hex input. OK accepts and Cancel/outside/Back restores the original. The editor stays alive but hidden while a picker is open, then becomes visible after the picker dismissal callback, without extra dimming. Return tests check actual visibility and repeated picker use after queued callbacks.

Presets contain labels and editable app/chart settings, element highlight/hidden-content choices, font, update interval and private connection data. Tokens are AES-GCM encrypted with the existing app-private Android Keystore key; snapshots contain ciphertext/IV, never plaintext. Address/token comparisons use address and decrypted token values, not randomized ciphertext. Named preset files are in Downloads/ella-monitoring/presets. Loading validates the snapshot before committing settings and uses the normal reconnect/cancellation lifecycle. View values/Copy hides token/address. System default resets viewer settings while retaining the active connection and its comparison baseline.

Older presets migrate embedded font into the settings field, discard theme from preset comparison and retain their labels/settings. Presets that previously had no connection snapshot acquire the existing active connection during migration, preserving connectivity. Migration leaves older named theme files readable; writing a theme produces colour-only format 17.

PRESET • name and THEME • name are available on all pages; modifications show UNSAVED and the changed dot. One preset difference map controls selector state and changed-item colouring for Settings fields, chart setting controls, screen/lock icons and editable dashboard labels/headings. Save/update or restoring matching values clears differences. Automatic chart fallback is read-only and live readings/freshness never count as preset settings. Chart edits update indication immediately.

Appearance code adapts the owner's EQ reference without DSP/audio/vendor operations. Popups inherit the active app theme; summaries, charts, source bindings and calculations are retained.

In 0.24 Changed indicator occupies the slot beside Title outline. Indicator background and Voltages background sit together before gauge panels; Highlight 1 and Highlight 2 are paired and show their colour/hex values. Every readout/heading popup shows both colours and an exclusive highlight choice, plus Hide contents. Active preferences and named presets migrate old gauge-highlight booleans to Highlight 1 without clearing labels or connection data. Theme format 16 reads the legacy gaugeHighlight key and inherits old panel colours for the new bounding-box roles.

Picker callbacks repaint existing view backgrounds/text/gauge palette immediately, including valid typed hex. They do not rebuild the viewport or perform repeated preset snapshots. The saved-theme baseline is loaded once per editor/picker opening. OK/Cancel synchronously restores the retained editor after dismiss, with rollback on cancellation; no full-page rebuild is queued. Opening from Settings/Charts exposes Live data once so colour changes have a visible dashboard preview, following the EQ reference. Physical-device response time remains to verify.

Keep screen awake, Full screen and Lock are independent app-wide states. Their values are excluded from new preset JSON, normalized older presets and difference checks. Loading named presets or System default preserves their current values; their ordinary app preference persistence is unchanged.

In 0.25 Button border occupies the formerly blank editor slot beside Button background, including its swatch/hex value. It saves, previews, copies and compares independently. Older files inherit this role from Controls; bottom-bar Controls/Off button border are unchanged. Font selection stays in presets and receives the preset changed-item indication even though its control lives in Edit theme. Both Save changes confirmations share the approved name-dialog padding, equal-height/equal-weight buttons and app theme; other dialog padding is unchanged.

In 0.26 PresetStore moves named presets to JSON files in Downloads/ella-monitoring/presets using the existing theme storage approach shared by DownloadsFiles. Successful migration removes the private original only after the file is saved; failures keep it. Conflicts create a separate migrated name, updating the selected preset. Normalized state remains separate from name/presetFormat metadata. The selected comparison baseline is cached, avoiding file reads for each changed-label check; explicit load/save/rename/delete updates it. External file edits are revalidated on explicit load.

SavedJson enforces a 64 KB file limit, valid UTF-8 and strict complete JSON grammar with a bounded nesting depth, duplicate-key rejection and no trailing content. PresetState validates known types/ranges/enums, label lengths, legacy flags/font and encrypted connection structure. Theme validation accepts supported formats and older missing roles, but rejects malformed supplied colour fields rather than coercing defaults. Invalid files are excluded from menus with feedback; failed loads preserve active values. Names exclude separators/control characters/reserved defaults. Current theme format remains 17; new preset metadata uses presetFormat 1. Tokens remain AES-GCM ciphertext/IV, tied to the original installation's Keystore. Decryption/authentication is staged before committing a loaded preset. No plaintext token export is introduced.

Legacy writes use temporary files and rename; MediaStore replacements retain the old bytes and restore them on a write failure, reporting an error if restoration itself fails. Created incomplete entries are removed. Failed migration retains private originals. These handling checks are synthetic, not a claim of crash/power-loss atomicity or real-device storage verification.
